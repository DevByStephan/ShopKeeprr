# Examples

These examples are small, readable starting points for ShopKeeprr 1.1.0 extensions. They are not release packages and they are not a substitute for testing on a staging store.

- [Hello ShopKeeprr module](plugin/hello-shopkeeprr/README.md) — a module with a manifest, service provider, account route and Blade view.
- [Atelier Example theme](theme/atelier-example/README.md) — a theme palette and homepage override built on the core storefront layout.

## Rules

- Do not add a release ZIP to this repository.
- Do not add credentials, customer data or license keys.
- Keep examples compatible with ShopKeeprr 1.1.0.
- Test PHP syntax and JSON manifests before opening a pull request.

The free core application is available from [shopkeeprr.com](https://shopkeeprr.com/); extension packages remain available through [ShopKeeprr Store](https://store.shopkeeprr.com/).
